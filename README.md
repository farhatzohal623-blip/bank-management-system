# 🏦 Bank Management System

## 📌 Project Overview
This project is a Python-based Bank Management System developed using Object-Oriented Programming (OOP) principles and software design patterns. It simulates core banking operations while demonstrating clean code structure and modular software design.

---

## ⚙️ Features
- Customer account creation
- Deposit and withdrawal operations
- Savings and checking account support
- Account balance management
- File-based data storage
- Modular and extensible system design

---

## 🧠 OOP Concepts Demonstrated
- Classes and Objects
- Inheritance
- Abstraction
- Encapsulation
- Polymorphism

---

## 🏗️ Design Patterns Used
- Singleton Pattern
- Factory Pattern
- Template Method Pattern
- Strategy Pattern

---

## 📂 Main Classes
- `Bank`
- `Customer`
- `AbstractAccount`
- `SavingsAccount`
- `CheckingAccount`

---

## 🛠️ Technologies Used
- Python
- Object-Oriented Programming (OOP)
- JSON / File Handling

---

## 📁 Project Structure
- `bank_system.py` → Main banking system implementation
- `bank_system_commented.py` → Commented version for learning and explanation
- `requirements.txt` → Project dependencies
- `diagrams/` → UML diagrams and system design visuals

---

## 🚀 How to Run the Project

1. Clone the repository
2. Make sure Python is installed
3. Run:

```bash
python bank_system.py
